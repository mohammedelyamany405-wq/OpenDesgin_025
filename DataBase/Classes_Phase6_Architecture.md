# المرحلة 6 — نظام Classes منظم

## الهدف
تقليل تكرار CSS ورفع قابلية القراءة في الملف المصدَّر، دون أي تخمين:
1. أسماء أصناف مفهومة مشتقة من اسم الطبقة الذي كتبه المصمم (بدل `wb-<id>`).
2. دمج العناصر ذات التنسيق المتطابق في صنف واحد مشترك.
3. «أصنافي»: حفظ التنسيق البصري لعنصر كصنف مسمّى قابل لإعادة الاستخدام على أي عنصر آخر.

## ما لا يتغيّر
- الأصناف الجاهزة (Layout/Text/Spacing/Colors/Effects) تبقى كما هي.
- كل عنصر يحتفظ بقواعده الخاصة (مقاس/تخطيط/موضع) — لا دمج يخلط خصائص عنصرين مختلفين.
- لا تحويل X/Y، ولا استنتاج تخطيط.

## 1. تسمية الأصناف المولّدة
- الأساس = `node.name` (اسم الطبقة) عبر `cssClassSlug`:
  - حروف صغيرة، مسافات/`_` ← `-`، حذف الرموز غير الصالحة.
  - تُقبل الحروف غير اللاتينية (العربية) لأن CSS يسمح بها.
  - إن بدأ الاسم برقم ← سابقة `el-`.
  - اسم فارغ ← `el`.
- التفرّد عبر `createClassNamer(reserved)`: عند التكرار `name-2`, `name-3`...
- الأسماء المحجوزة = أسماء الكتالوج + أسماء «أصنافي» لمنع التعارض.

## 2. دمج القواعد المتطابقة
- مفتاح الدمج = نص قواعد العنصر الأساسية + التابلت + الموبايل.
- أول عنصر بالمفتاح يحصل على الاسم المولّد؛ العناصر التالية تعيد استخدام نفس الصنف.
- عناصر ذات مواضع حرّة مختلفة لا تُدمج (لأن `left/top` مختلفة) — سلوك مقصود.

## 3. «أصنافي» (Style Classes)
- التخزين: `pluginData` على الصفحة الحالية، مفتاح `web-builder-style-classes`:
  `[{ name: string, declarations: string[] }]`.
- **الحفظ**: يأخذ **التنسيق البصري فقط** (تعبئة صلبة/تدرّج، حدود، استدارة، ظل، ضبابية، شفافية، خطوط)
  ويستثني المقاس/التخطيط/الموضع **والصور** (حتى لا تتكرر بيانات الصورة داخل سجل الصفحة).
- **التطبيق**: يضيف الاسم إلى `web-builder-classes` للعنصر (مع الأصناف الجاهزة).
- **الحذف**: يزيله من سجل الصفحة ومن العنصر المحدد فقط (المراجع القديمة على عناصر أخرى تبقى بلا CSS — تُنظَّف عند إعادة الحفظ).
- التطبيق على الحفظ: حفظ الصنف يطبّقه فوراً على العنصر الحالي.

## ترتيب CSS في الملف المصدَّر
1. `body` + قاعدة أمان الصور.
2. الأصناف الجاهزة المستخدمة.
3. القواعد الخاصة بالعناصر (مقاس/تخطيط/موضع/بصري).
4. أصناف «أصنافي» المستخدمة — بعد قواعد العناصر لتتغلب عليها (تطبيق الصنف يغيّر المظهر فعلاً).
5. `@media` للتابلت ثم الموبايل.

## الواجهة
`ClassesTab.vue` جديد (بدل كتلة داخل `WebBuilderPanel.vue`):
- «Applied»: أسماء مطبقة مع زر إزالة.

- الكتالوج الجاهز كما هو.
